# GardenGuide Australia

A mobile-first Australian vegetable gardening companion.

## First working build

- Searchable vegetable planting guide
- Sowing depth, spacing, harvest timing and growing tips
- My Garden saved locally on the device
- Plant Doctor photo capture/upload prototype
- Location permission workflow ready for future climate-zone recommendations
- Responsive phone/desktop interface

## Next build priorities

1. Australian climate zones and postcode/locality lookup
2. Region-specific sowing calendars
3. Weather and frost/rain guidance
4. Plant photo diagnosis
5. Larger crop database
6. Planting reminders and garden calendar
7. Installable PWA/mobile packaging

Open `index.html` to run the current prototype.
